# Criterios de Clasificación de Recursos Académicos

Para mantener una estructura organizada, cada recurso registrado en el sistema debe incluir al menos los siguientes cuatro criterios de clasificación:

1. **Tipo de Recurso**
   * Categorización según el formato del material.
   * *Ejemplos:* Libro, Artículo científico, Video tutorial, Documentación oficial, Ejercicio práctico.
   * HOLA MUNDO 
   * PRIN("HELLO WORLD")

2. **Tema o Área de Conocimiento**
   * Materia o disciplina a la que corresponde el material.
   * *Ejemplos:* Programación, Estructuras de Datos, Big Data, Matemáticas Discretas.

3. **Nivel Educativo / Dificultad**
   * Grado de conocimiento previo requerido para aprovechar el contenido.
   * *Niveles:* Introductorio, Intermedio, Avanzado.

4. **Autor o Fuente**
   * Entidad, profesor, investigador o institución responsable de la elaboración del contenido.
   * *Ejemplos:* Universidad Nacional, Guido van Rossum, IEEE, Documentación de Python.
