# Gestor de Recursos Académicos

## Descripción
El **Gestor de Recursos Académicos** es una herramienta diseñada para organizar, clasificar y acceder de forma eficiente a material educativo digital como libros, artículos, manuales y ejercicios. Permite mantener un inventario estructurado para facilitar la búsqueda y consulta de información académica.

## Objetivo
Proporcionar un punto centralizado para la administración de insumos educativos, optimizando el tiempo de búsqueda y garantizando la trazabilidad de los materiales utilizados en entornos de estudio e investigación.
